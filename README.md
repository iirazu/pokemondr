# PokemonDR

Juego de navegador estilo Pokémon pensado para móviles. Sin dependencias: HTML + CSS + JavaScript.

## Cómo jugar
- Mueve al personaje con la cruceta táctil (o flechas / WASD en PC).
- Camina por la hierba alta para encontrar criaturas salvajes.
- Combate por turnos: Luchar, Bola, Poción, Equipo, Huir.
- Las ventajas de tipo (fuego, agua, planta, normal) multiplican el daño.
- Captura criaturas con bolas; cuanto menos vida tengan, más fácil.
- El edificio 🏥 al norte del inicio cura al equipo y repone bolas y pociones.
- El progreso se guarda en localStorage.

## Ejecutar
Abre `index.html` en el navegador, o sirve la carpeta: `python3 -m http.server 8000`.

## Publicar
Activa GitHub Pages en Settings > Pages (rama main, carpeta root). Las páginas de repos privados requieren plan de pago.
